# Design

Put sketches, wireframes, user flows and architecture diagrams here once the problem definition (G1) is approved.

Planned v1 user flow (job-seeker side only):

1. The student opens JobBridge and picks a short, realistic coding task.
2. The student solves it and submits the code (e.g. a GitHub link).
3. AI reviews it: code quality, tests, SQL, Git usage, communication.
4. The student gets a skill report as a shareable link or PDF and attaches it to job applications.
