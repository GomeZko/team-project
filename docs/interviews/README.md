# Client interviews

Notes from interviews with junior developers looking for their first job. They are the evidence behind `docs/PRODUCT.md`.

**Rules**

- Never write the interviewee's real name here. Use a role and a number, e.g. `interview-01-junior-bootcamp.md`.
- Write down what the person actually said. Mark your own interpretations as **[our note]**.
- If a number is self-reported, label it as an estimate.
